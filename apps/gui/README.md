# Atelier GUI

This directory is reserved for Atelier's future desktop GUI application.

The GUI has not been implemented yet. When development starts, keep the
application entrypoint, UI-specific tests, assets, and packaging under this
directory. Reusable protocol and runtime functionality should remain in
`packages/` or `crates/` behind explicit interfaces.

See [`docs/REPOSITORY_LAYOUT.md`](../../docs/REPOSITORY_LAYOUT.md) for monorepo
placement rules.
